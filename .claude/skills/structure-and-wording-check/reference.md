# Structure and wording check: house style and checks

## House style for rewrites

| Use | Not | Why |
|---|---|---|
| Armour, Defence | Armor, Defense | The stats are "Physical Defence" and "Magical Defence" |
| turns ("for 3 turns") | rounds | The app ticks effects down once per Process Turn press, and treats "3 rounds" as 3 ticks |
| once per combat | once per scene / encounter | The New Combat button resets "per combat" uses |
| Saving Roll with a difficulty ("Hard Saving Roll (14)") | "save", "saving throw" | The rules define a ladder: Super Easy 3, Easy 8, Normal 11, Hard 14, Extreme 17 |
| Stamina | mana | There is no Mana stat |
| a number ("within 15ft", "Speed −2", "for 2 turns") | nearby, small, slows, briefly | Numbers stop table arguments |
| "Roll once (20%): on a success, both X and Y" or "20% chance each" | "20% chance to apply X and Y" | Says whether it is one roll or two |

Durations end with a number of turns, "until the end of combat", or "until your next turn".

## How each check works

- **Mixed terms**: counts each spelling across all text and lists the uses of the form that should change.
- **Vague wording**: looks for "nearby", "slows enemies", "or similar"/"etc"/"as appropriate", size words (small/large/massive/minor) in a sentence with no number, and comparisons (stronger/weaker/hotter/faster).
- **Bonus with no duration**: active skills that grant or apply a +bonus with no turn/round/until/while/combat/rest wording.
- **Text and app disagree**: for "N% chance to apply X (and Y)", checks the skill's built-in effects. If X or Y is missing, the app's action bar never applies it. If the chance differs, the app rolls a different number than the card says.
- **One chance, two statuses**: "N% chance to apply X and Y" without "both" or "each".
- **Status named but not defined**: "apply Something" where Something is not in the status list.
- **Used in skills, never explained**: long rest, short rest, friendly fire, difficult terrain, per day, reaction, Advantage, concentration, Harmony — used on skill cards but not found in How to Play or the Glossary.
- **Rules that disagree**: How to Play and the Glossary mention Advantage, while the game's own rules audit treats Advantage as a D&D term to avoid.

## Known limits

Checks read words, not meaning. A size word next to a number, or a vague word inside a name (e.g. "Mana Mastery" is a tag name), can be a false alarm. Always check before reporting.
